# 絶エデン P2 氷滑り　ダイアモンドダスト練習

絶エデン P2「ダイアモンドダスト」の氷滑りを、PC＋ゲームパッド／キーボードで繰り返し確認するためのイメトレ用シミュレータです。

実際のゲームを完全再現するものではなく、主に以下の練習を目的にしています。

- カメラ角度を合わせて滑る
- 左スティックの細かな入力角度を意識する
- ボス位置と自分の立ち位置から滑走方向を判断する
- ボス背面側の安置へ滑る
- ボス側／対角側のさまざまな開始位置をイメージする

## 推奨環境

- PC
- Chrome / Edge などのモダンブラウザ
- ゲームパッド推奨
- キーボードでも操作可能

FF14本体が動作するほどのPC性能は必要ありません。ブラウザ上の軽量な描画で動作します。

## 基本操作

- **左スティック / WASD**：移動
  - 滑走モード：入力した方向へ直線的に滑走
  - 徒歩モード：通常移動
- **右スティック**：カメラ上下左右
- **矢印キー**：カメラ上下左右
- **マウスドラッグ**：カメラ上下左右
- **マウスホイール**：ズームイン / ズームアウト
- **キャラクターをドラッグ**：任意の位置へ配置

PADの各機能は画面内の「ボタン配置」から変更できます。

ゲームパッドが反応しない場合は、接続し直してみてください。

## 操作ボタン

### 立ち位置＋カメラ角度ランダム

主な練習用ボタンです。

- ボス位置：8方向のいずれか
- キャラ位置：3本目の円付近
- 開始区間：
  - ボス側区間
  - ボス対角側区間
- カメラ角度：ランダム

「詳細設定」の **ボス側からスタートしない** をONにすると、対角側区間からの開始だけになります。

### カメラ角度のみランダム

- ボス：A方向固定
- キャラ：南側固定
- カメラ角度だけランダム

### リセット

- ボス：A方向
- キャラ：南側3本目の円
- カメラ：A方向

## 詳細設定

折りたたみ内で以下を調整できます。

- ボス側からスタートしない
- 視点の高さ
- キャラの画面内上下位置
- カメラ速度
- 視野角
- 滑走距離
- 安置の角度幅
- 滑走開始感度

数値は練習しやすさや実際のプレイ感に合わせて調整してください。

## マーカー

数字マーカーはボタンで以下を切り替えられます。

- 1234
- 2341

## 注意

このページはギミック処理や入力感覚を確認するためのイメトレ用シミュレータです。ゲーム内の物理挙動・判定・カメラ挙動を完全に再現するものではありません。

# FRU P2 Ice Slide - Diamond Dust Practice

This page is an image-training simulator for practicing the ice slide mechanic in FRU P2 "Diamond Dust" with a PC plus gamepad or keyboard.

It is not a full recreation of the in-game mechanic. Its main goal is to help you repeatedly practice and visualize the following:

- aligning the camera and sliding in the intended direction
- being aware of small left-stick angle differences
- judging your slide path from the boss position and your own starting position
- sliding into the rear safe zone behind the boss
- visualizing starts from both boss-side and opposite-side sectors

## Recommended Environment

- PC
- A modern browser such as Chrome or Edge
- Gamepad recommended
- Keyboard also supported

This page is lightweight and browser-based, so it does not require the same PC performance as running FF14 itself.

## Basic Controls

- **Left stick / WASD**: movement
  - Slide mode: one input makes you slide in a straight line
  - Walk mode: normal movement
- **Right stick**: camera up/down/left/right
- **Arrow keys**: camera up/down/left/right
- **Mouse drag**: camera up/down/left/right
- **Mouse wheel**: zoom in / zoom out
- **Drag the character**: place the character at any position

You can change gamepad mappings from the "Button Mapping" section in the page.

If the gamepad does not respond, try reconnecting it.

## Control Buttons

### Random Position + Camera

This is the main practice button.

- Boss position: one of 8 directions
- Character position: near the third ring from the center
- Start sector:
  - boss-side sector
  - opposite-side sector
- Camera angle: random

If you enable **Do not start from the boss-side sector** in Detailed Settings, only opposite-side starts will be generated.

### Random Camera Only

- Boss: fixed at A
- Character: fixed on the south side
- Only the camera angle becomes random

### Reset

- Boss: A direction
- Character: south-side third ring
- Camera: facing A

## Detailed Settings

Inside the collapsible section, you can adjust:

- Do not start from the boss-side sector
- Camera height
- Character screen Y position
- Camera speed
- Field of view
- Slide distance
- Safe-zone angle
- Slide start sensitivity

Adjust these values to match your practice preferences and your in-game feel.

## Markers

The number markers can be switched between:

- 1234
- 2341

## Notes

This page is an image-training simulator for checking movement ideas and practicing the mechanic. It does not perfectly reproduce in-game physics, hit detection, or camera behavior.
